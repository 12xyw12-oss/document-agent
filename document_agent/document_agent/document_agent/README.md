# 企业文档智能处理与知识沉淀 Agent

基于多 Agent 协作的企业文档智能处理与知识沉淀系统，实现从文档采集到知识应用的全流程自动化。

## 🎯 核心痛点解决

针对企业文档管理的五大核心痛点提供解决方案：

| 痛点 | 解决方案 |
|------|----------|
| 信息孤岛 | 统一对接飞书、钉钉、Git、共享盘等多平台 |
| 检索效率低 | 非结构化文档智能解析 + 向量检索 |
| 知识流失 | 结构化知识沉淀 + 知识图谱关联 |
| 新人上手慢 | 智能问答 + 个性化知识推荐 |
| 协作信息不对称 | 跨文档推理 + 知识网络构建 |

## 🧠 Agent 角色说明

### 1. 文档采集 Agent
- 支持 Word、PDF、PPT、Excel、Markdown 等 12+ 种格式文档
- API 对接企业内部主流文档平台（飞书、钉钉、Git、共享盘）
- 内置基础权限校验机制，遵循企业数据安全规范
- 根据来源、创建时间、作者、标签等维度自动分类归档

### 2. 内容解析 Agent
- OCR 识别与格式清洗，去除页眉页脚、水印等无效信息
- 提取核心主题、关键结论、数据指标、责任人、时间节点等结构化信息
- 实体关系抽取，构建团队专属知识图谱
- 关联分散文档中的知识点，形成完整知识网络

### 3. 检索问答 Agent
- 向量数据库 + 知识图谱混合检索
- 支持自然语言提问，精准定位文档段落
- 提供答案来源与上下文引用
- 复杂问题自动调用多文档进行跨文档推理
- 个性化推荐，根据岗位与历史查询推送相关知识

### 4. 更新维护 Agent
- 每日增量同步机制，自动更新知识图谱
- 用户反馈闭环系统，持续优化解析与检索模型
- 定期清理过期文档与无效信息
- 保证知识库的时效性与准确性

## 🛠️ 技术栈

| 模块 | 技术 |
|------|------|
| 框架 | LangChain |
| 大语言模型 | OpenAI GPT-3.5/4 |
| 向量数据库 | Chroma |
| 知识图谱 | 自定义 JSON 存储 |
| 前端界面 | Gradio |
| 文档处理 | PyPDF、python-docx、openpyxl |

## 📦 安装依赖

```bash
cd document_agent
pip install -r requirements.txt
```

## ⚙️ 配置说明

1. 创建 `.env` 文件：

```env
OPENAI_API_KEY=your-api-key-here
OPENAI_BASE_URL=https://api.openai.com/v1
```

2. 配置文件说明 (`config.py`)：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| LLM_MODEL | 大语言模型 | gpt-3.5-turbo-1106 |
| EMBEDDING_MODEL | 嵌入模型 | text-embedding-3-small |
| CHUNK_SIZE | 文档分割大小 | 1000 |
| CHUNK_OVERLAP | 分割重叠长度 | 200 |

## 🚀 启动运行

```bash
python main.py
```

启动后访问 Gradio 界面，即可使用以下功能：

1. **文档管理** - 上传文档、构建索引、增量同步
2. **智能问答** - 自然语言提问、获取答案
3. **系统状态** - 查看文档数、向量数、实体数等统计信息

## 📋 使用流程

1. **上传文档** → 在"文档管理"标签页上传企业文档
2. **构建索引** → 点击"构建/重建索引"生成向量和知识图谱
3. **智能问答** → 在"智能问答"标签页输入问题获取答案
4. **反馈优化** → 对回答进行评分和评论，帮助系统持续优化
